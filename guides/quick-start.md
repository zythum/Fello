# 快速开始

> 💡 **目标：** 5 分钟内完成 Fello 的安装，并发起你的第一次 AI 对话。

## 第一步：下载与安装

前往 GitHub Releases 下载适合你操作系统的安装包：

👉 [Fello Releases - GitHub](https://github.com/Zythum/fello/releases)

| 平台 | 文件格式 | 安装方式 |
|------|---------|---------|
| macOS | .dmg | 双击打开，拖入 Applications |
| Windows | .exe | 双击运行安装向导 |
| Linux | .AppImage / .deb | 赋予执行权限后运行，或 dpkg 安装 |



---

## 第二步：配置你的第一个 Agent

Fello 支持两种 Agent 类型，选择适合你的方式：

### 本地 Stdio Agent（推荐）

> 💻 通过 ACP 协议运行本地命令行 Agent，数据完全在本地，隐私安全。

### API Agent

> 💡 连接 OpenAI 兼容 API 服务，支持流式文本和推理。需要配置 API 地址和密钥。

详细配置方法请参考 → [Agent 配置与管理](./agents.md)

---

## 第三步：导入项目

> 💡 **提示：** 项目以工作目录为单位组织。Agent 将以该目录为上下文进行文件操作和代码理解。

Fello 以**工作目录（项目文件夹）**为单位组织你的工作。每个项目对应磁盘上的一个文件夹，Agent 将以该目录为上下文进行文件操作和代码理解。

### 添加方式

- **桌面客户端** — 点击左侧边栏底部的「添加项目」按钮，在弹出的系统文件选择器中选中目标文件夹即可。
- **WebUI 模式** — 点击「添加项目」后，在弹窗中输入服务器上的绝对路径（如 `/home/user/my-project`）并确认。

### 操作步骤

1. 点击左侧边栏的「+ 添加项目」按钮
2. 选择或输入你的项目文件夹路径
3. 项目添加成功后，会自动弹出「新建会话」对话框
4. 选择要使用的 Agent，点击确认即可开始对话

### 项目管理

添加项目后，你可以在侧边栏对项目进行以下操作：

| 操作 | 说明 |
|------|------|
| 重命名 | 右键项目名称，选择「重命名」，自定义显示名称（不影响实际文件夹） |
| 在访达 / 资源管理器中打开 | 快速跳转到该文件夹的系统位置 |
| 删除项目 | 从 Fello 移除项目（不会删除磁盘文件），同时清除关联的所有会话 |

> ✅ **完成！** 项目添加后，左侧边栏会展开该项目，你可以在其下创建多个会话，每个会话可使用不同的 Agent 和 MCP 配置。

---

## 第四步：发起第一次对话

添加项目后，你就可以开始与 AI Agent 对话了：

1. 点击项目旁的「+ 新会话」按钮，或在上一步自动弹出的对话框中操作
2. 选择要使用的 **Agent**（如 kiro 或你配置的 API Agent）
3. （可选）勾选需要启用的 **MCP 服务器**，为 Agent 扩展额外工具能力
4. （可选）设置**权限模式**：「每次询问」更安全，「始终允许」更流畅
5. （可选）开关**功能（Features）**选项，控制会话中 Agent 的能力范围
6. 确认后进入对话界面，在底部输入框输入你的第一条消息
7. 按 **Enter** 发送，Agent 将以流式方式逐步响应

> 💡 **试试这些提示语：**
> - 「帮我看看这个项目的结构」— 了解项目概览
> - 「这个项目用了什么技术栈？」— 快速掌握技术细节
> - 「帮我写一个 README」— 让 Agent 为你生成文档
> - 「找到所有 TODO 注释」— 搜索项目中的待办事项

### 功能开关（Features）

新建会话时，你可以通过开关控制 Agent 在本次会话中可使用的功能：

| 功能 | 说明 |
|------|------|
| **技能（Skills）** | 启用后 Agent 可调用已安装的技能包（如 lark 系列技能），获得更专业的领域能力。关闭则仅使用基础对话和工具能力。 |
| **向我提问（Ask User）** | 启用后 Agent 在信息不足时可以主动向你提问以澄清需求，对话更精准。关闭则 Agent 将自行推断而不中断流程。 |

> 💡 **默认两项功能均为开启状态。** 一般建议保持默认，除非你有特定原因需要限制 Agent 的能力范围。

对话过程中，Agent 可能会请求使用工具（如读取文件、执行命令）。首次调用时会弹出**权限确认弹窗**，你可以选择「允许」或「始终允许」来记住该授权。
