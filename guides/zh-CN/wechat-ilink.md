# 微信 iLink

> 💬 **微信 iLink** 让你将 Fello 接入微信，在桌面端直接收发微信消息。你可以将微信对话转发给 AI Agent 处理，或通过 Fello 回复微信消息。

## 功能概览

- 📥 **接收消息** — 微信消息实时同步到 Fello，在桌面端统一查看
- 📤 **发送回复** — 通过 Fello 直接回复微信消息，支持长文本自动分段

---

## 连接微信


### 配置步骤

1. 打开 Fello → **Settings**
2. 找到 **WeChat iLink** 区域
3. 点击 **Connect**（连接）
4. 使用微信扫描弹出的二维码
5. 在手机微信上确认登录

> 💡 **注意：** 登录凭证会持久化存储，下次启动 Fello 时自动恢复连接。如需断开，在设置中点击 Disconnect。

---

## 使用方式


### 设置活跃会话

连接微信后，你需要指定一个 AI 会话来处理收到的微信消息：

1. 在左侧边栏中，右键点击某个会话
2. 选择 **「设为微信活跃会话」**
3. 该会话将出现微信标识，表示已绑定
4. 收到的微信消息会自动注入到该会话，Agent 的回复也会通过微信发送

> 💡 **切换活跃会话：** 你可以随时右键另一个会话重新设定。同一时间只有一个会话是活跃的。取消绑定同样通过右键菜单「取消微信活跃」。

### 消息收发

| 功能 | 说明 |
|------|------|
| 接收消息 | 微信消息实时同步到 Fello 的活跃会话 |
| 回复消息 | Agent 的回复自动通过微信发送给对方 |
| 长文本分段 | 超过 2000 字符的回复自动分段发送（微信限制） |
| 输入状态 | Agent 处理中时，对方可看到"正在输入"状态 |

### 微信 ! 命令

在微信中发送以 `!` 开头的消息即为命令。命令会**中断当前 Agent 执行**（如正在生成回复则立即取消），然后执行对应操作：

| 命令 | 功能 | 说明 |
|------|------|------|
| `!s` | **切换会话** | 列出所有会话（按项目分组），回复序号切换到对应会话 |
| `!n` | **新建会话** | 列出所有项目，回复序号在该项目下创建新会话并自动切换 |
| `!m` | **切换模型** | 列出当前会话可用的模型，回复序号切换（仅 API Agent 支持） |
| `!p` | **切换权限** | 列出权限模式（每次询问 / 全部允许），回复序号切换；即时生效，**不重启会话** |
| `!f` | **切换功能** | 列出当前会话的功能开关，回复序号切换；切换后会**重启会话**以使改动生效 |
| `!c` | **切换 MCP** | 列出当前会话的 MCP 服务器开关，回复序号切换；切换后会**重启会话**以使改动生效 |
| `!q` | **快捷短语** | 列出已配置的 Snippets，回复序号将对应内容发送给 Agent |
| `!` | **查看状态** | 显示当前活跃会话信息（标题、项目、Agent、权限、Features、MCP 状态） |

> 💡 **交互方式：** `!s`、`!n`、`!m`、`!p`、`!q` 命令执行后会返回编号列表，你只需回复对应的**数字序号**即可完成操作。例如发送 `!s` 后回复 `2` 即切换到第 2 个会话。

> 📝 **回复规则：** 菜单打开期间，以**数字开头**的回复被当作序号（序号超出范围会提示重试，菜单保持打开）；回复其他内容则被当作聊天消息，菜单自动关闭并把这句话发给 Agent。发送新命令也会直接关闭当前菜单。

> 🔁 **开关类命令：** `!f` 和 `!c` 是**多选**开关，回复序号会**立即应用**该开关并重启会话（功能与 MCP 只在会话加载时生效）。重启会中断当前 Agent 回复，但历史记录保留。列表会在每次切换后重新发送，方便连续切换多项；发送 `0` 退出菜单。

> 🔐 **权限命令：** `!p` 和 `!m` 一样是**单选**菜单：回复一次序号即完成切换，不会进入连续交互。权限模式在每次权限请求时读取，因此**不会重启会话**。改成「每次询问」后，Agent 的权限请求会推送到微信，回复序号即可选择允许 / 拒绝。

> ⚡ **中断功能：** 任何 `!` 开头的消息都会先取消正在进行中的 Agent 响应，然后再执行命令。因此即使只是想中断 Agent，发送任意 `!` 消息（如 `!stop`）即可。单独发送 `!` 查看当前状态与命令列表，以 `!` 开头的未知命令会收到「未知命令」提示。

## 典型使用场景

> 💡 **核心价值：只要 Fello 开着，你随时随地都能通过微信与 AI 协作。**

- 🚶 **移动办公** — 出门在外也能让 Agent 帮你处理工作，手机就是你的远程终端
- 🤖 **7×24 助手** — 把 Fello 挂在服务器上，微信随时唤醒 Agent 执行任务
- 👥 **分享给他人** — 让微信好友直接与你的 Agent 对话，无需安装任何软件

---

## 注意事项

> ⚠️ **注意事项：**
> - iLink 使用微信网页版协议，**部分微信账号可能不支持网页版登录**（微信的限制）
> - 长时间不活跃可能导致连接断开，需在 Settings 中重新扫码
> - 请遵守微信使用规范，避免频繁发送大量消息导致账号受限
> - 登录凭证持久化存储在本地，重启 Fello 后自动恢复连接
