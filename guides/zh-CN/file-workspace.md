# 文件工作区与终端

> 📁 **Fello 的右侧面板**集成了文件工作区和终端，让你在 AI 对话的同时浏览代码、预览文件、运行命令——无需切换窗口。

## 面板布局

Fello 界面从左到右分为四个区域：

| **Sidebar** | **Chat** | **Detail** | **Panel** |
|-------------|----------|-----------|-----------|
| 项目列表与会话导航 | AI 对话界面 | 文件预览 / 终端全屏 / Diff 视图 | Files 文件树 / Terminal 终端列表 |
| *可折叠* | *始终可见* | *按需展开，可关闭* | *固定宽度，标签页切换* |

> 🔗 **联动逻辑：** 在右侧 Files 中点击文件 → 左侧打开文件预览详情；在右侧 Terminal 中点击终端 → 左侧打开终端全屏视图。关闭详情视图后恢复为纯对话界面。

> 💡 **布局自适应：** 面板之间可通过拖拽分隔条调整宽度。当窗口宽度不足时，详情视图打开会自动隐藏对话区域以节省空间。

## 文件工作区（Files）

### 文件树浏览

- 分层加载，目录优先排序
- 点击文件在详情视图中预览
- 支持展开/折叠目录结构

### 文件操作

| 操作 | 说明 |
|------|------|
| 新建文件/文件夹 | 右键菜单或工具栏按钮创建 |
| 重命名 | 右键 → Rename，或选中后按 F2 |
| 删除 | 移入回收站或永久删除 |
| 拖拽移动 | 在文件树内拖拽文件/文件夹到目标位置 |
| 多选批量移动 | 按住 Cmd/Ctrl 多选后拖拽 |
| 外部拖入 | 从系统文件管理器拖入文件到 Fello |
| 在 Finder 中定位 | 右键 → Reveal in Finder |

### 文件预览

点击文件后在左栏的详情视图中预览，支持多种格式：

| 文件类型 | 预览方式 |
|---------|---------|
| 代码文件 | 语法高亮渲染 |
| Markdown | 富文本渲染 |
| 图片 | 图片渲染预览 |
| PDF | PDF 阅读器 |
| DOCX / XLSX | 文档预览 |

### Diff 对比视图

当 Agent 修改文件时，Fello 自动提供 Git 风格的双栏 Diff 对比视图：

- 左侧为修改前内容，右侧为修改后内容
- 变更行以红/绿色高亮标注，一目了然
- 你可以在审阅后决定是否接受修改

### 外部修改检测

Fello 通过文件系统监听实时检测已打开文件的外部变更。当文件被外部程序修改时：

- 右上角浮动显示蓝色提示条
- 点击刷新按钮即可加载最新内容

## 终端（Terminal）

### 创建和管理终端

1. 切换到右侧面板的 **Terminal** 标签页
2. 点击 **+** 按钮创建新终端
3. 在终端列表中点击切换不同终端
4. 点击 **×** 关闭不需要的终端

### 终端特性

| 特性 | 说明 |
|------|------|
| 多终端支持 | 每个项目可创建多个终端实例 |
| 全功能终端 | 基于 xterm.js + node-pty，支持完整的终端交互 |
| 自动 Resize | 终端大小随窗口自动适配 |
| 日志持久化 | 终端输出自动保存，会话恢复时可查看历史 |
| Agent 终端任务 | Agent 可发起独立终端任务并捕获输出 |

> 💡 **Agent 与终端的联动：** 当 Agent 执行命令时，你可以在终端面板中实时看到命令的输出过程。Agent 创建的终端任务也会出现在终端列表中，方便追踪和复查。
